A comparables-based quantile forecaster for GTA VI's launch-day Twitch viewers. It reads one case — the Twitch viewer count up to the end of hour 1 of release day — and forecasts hours 2–24 as five quantiles each (5%, 25%, 50%, 75%, 95%), built from the hourly curves of 38 past big launches. On the kit's four practice launches it scores a pinball loss of about 0.18 against the house baseline's 0.387.

## Run it

```sh
python3 main.py
```
